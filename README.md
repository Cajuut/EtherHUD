***

EtherHUD is a next-generation HUD mod designed to display essential information beautifully without compromising your Minecraft experience. No complex setup required—from the moment you install it, EtherHUD delivers a sleek, modern interface directly to your screen.

## Technical Highlights
***
* **Ultralight Performance**
  Highly optimized code structure designed to deliver essential data with zero impact on your framerate.
* **Modern Aesthetics**
  A clean, sophisticated UI inspired by contemporary design trends and glassmorphism.
* **Smart Layout**
  Precisely calculated typography and positioning that blends seamlessly with the vanilla gameplay feel.
* **Modular Display**
  Fully customizable modules including FPS, Coordinates, Durability, and CPS. Only see what you need.

## Philosophy
***
EtherHUD follows the "beauty of subtraction," providing an ethereal presence that stays out of your way while keeping you informed. It is built for players who value both performance and a clean workspace.

## Compatibility
***
* **Versions:** 1.21.x (Fabric / Quilt)
* **Technical Dependencies:** Fabric API / Cloth Config API (Recommended)
