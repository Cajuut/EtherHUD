# EtherHUD

[English](README.md) · [日本語](README_ja.md) · [简体中文](README_zh_cn.md) · [繁體中文](README_zh_tw.md) · [한국어](README_ko.md)

## 설치

EtherHUD는 **Minecraft 1.21.4 / Fabric**용 클라이언트 HUD 모드입니다. **Java 21**, **Fabric Loader 0.16.14 이상**, Minecraft 1.21.4용 **Fabric API 0.119.2 이상**이 필요합니다. EtherHUD와 Fabric API를 인스턴스의 `mods` 폴더에 넣고, 게임에서 **오른쪽 Shift**를 눌러 설정을 엽니다. Mod Menu에서도 열 수 있습니다. Mod Menu와 Cloth Config는 선택 사항입니다.

## 설정과 팁

모듈별로 표시 여부를 바꾸거나 전체 스위치로 HUD를 잠시 숨길 수 있습니다. 모듈 옆 설정에서 색상 선택기와 미리보기를 사용해 글자, 배경, 테두리, 모서리, 크기, 위치를 조정합니다. 처음 설정을 열면 조작할 곳에 테두리를 표시하는 팁 6개가 나옵니다. **더 보기 → 팁 다시 보기**에서 다시 볼 수 있습니다. 설정은 화면을 닫을 때 저장됩니다.

## HUD 모듈

| 모듈 | 표시 내용 |
| --- | --- |
| FPS | 현재 프레임 속도 |
| Coordinates | 플레이어 좌표 |
| CPS | 왼쪽과 오른쪽 버튼의 초당 클릭 수 |
| Armor Status | 주 손, 보조 손, 방어구와 내구도 |
| Ping | 멀티플레이 연결 지연 시간 |
| TPS | 서버 시간 갱신으로 추정하는 틱 속도 |
| Player Model | 시선 방향에 따라 회전하는 플레이어 3D 모델 |
| Item Total | 주 손의 아이템과 같은 종류의 인벤토리 내 총수 |
| Compass | 시선 방향에 따라 움직이는 방위와 각도 눈금 |
| Image Overlay | 로컬 이미지나 움직이는 GIF |

Armor Status는 분리형, 일체형, 바닐라 단축바 스타일과 가로·세로 배치를 지원합니다. 내구도 경고도 설정할 수 있습니다. 바닐라 스타일은 단축바나 인벤토리 화면 옆에 붙이거나 직접 배치할 수 있고, 크기는 Minecraft의 GUI 배율을 따릅니다. Image Overlay는 PNG, JPEG, GIF, BMP, WBMP, TIFF를 지원합니다.

## HUD 편집기

설정에서 **HUD 편집기**를 엽니다. 모듈을 끌어 이동하고, 모서리를 끌거나 **Ctrl＋휠**로 크기를 조정합니다. **Ctrl＋우클릭**으로 선택에 추가하거나 제외하고, 빈 곳에서 끌어 범위를 선택합니다. 방향키로 미세하게 움직이고 **Shift**를 누르면 더 크게 움직입니다. **Ctrl＋Z / Ctrl＋Y**로 실행 취소 또는 다시 실행하고, **H**로 도구 모음을 표시하거나 숨깁니다. 도구 모음에서는 스냅, 격자, 비활성화된 모듈 미리보기를 설정할 수 있습니다. **Esc**는 우클릭 메뉴를 먼저 닫고, 메뉴가 닫혀 있으면 저장하고 종료합니다. **취소**를 누르면 이번 편집 내용이 저장되지 않습니다.

## Overlay

**더 보기 → Overlay**에서 불사의 토템 애니메이션 크기, 높이, 속도(25–300%, 기본 100%)를 조절합니다. 1인칭 불꽃의 높이, 월드의 불 및 영혼 불 크기, 양손에 든 아이템의 크기와 높이, 방패 불투명도도 조절할 수 있습니다. 월드 불 크기는 설정 화면을 닫으면 청크 렌더링에 반영됩니다.

설정은 인스턴스의 `config/etherhud.json`에 저장됩니다. 인터페이스는 5개 언어를 지원하며 모듈 이름은 영어로 표시됩니다. 라이선스는 [MIT](LICENSE)입니다.
