# EtherHUD

[English](README.md) · [日本語](README_ja.md) · [简体中文](README_zh_cn.md) · [繁體中文](README_zh_tw.md) · [한국어](README_ko.md)

Minecraft **1.21.4 / Fabric** 用のクライアント HUD Mod です。必要な情報だけを表示し、ゲーム内で配置・サイズ・配色を調整できます。

## 導入

1. **Java 21**、**Fabric Loader 0.16.14 以上**、Minecraft 1.21.4 用の **Fabric API 0.119.2 以上**を用意します。
2. EtherHUD と Fabric API の JAR をクライアントの `mods` フォルダーに入れます。
3. ゲーム内で **右 Shift** を押して EtherHUD の設定を開きます。Mod Menu の設定ボタンからも開けます。

Mod Menu と Cloth Config は任意です。同梱ライセンスは [MIT](LICENSE) です。

## 設定と Tips

- 各行のスイッチでモジュールを切り替えます。右上の **HUD 全体** スイッチは、個別の設定を保持したまま HUD をまとめて表示・非表示にします。
- 各行の **設定** で、背景色と不透明度、文字色と影、アウトラインの色と有無、角の丸さ、サイズ、アンカー、位置を調整できます。色はカラーピッカーで選べます。
- 初回は操作する場所を枠で示す Tips が6件あります。対象のボタンやスイッチは案内中も操作できます。**次へ** で進み、**Tipsを終了** または **Esc** で閉じます。再表示は **その他 → Tipsをもう一度見る** です。
- **その他** には一括切り替え、Overlay、リセット、シェーダー描画の切り替えがあります。設定の変更は画面を閉じると保存されます。
- UI は英語、日本語、簡体字中国語、繁体字中国語、韓国語に対応します。モジュール名は全言語で英語です。

## HUD モジュール

| モジュール | 表示内容 |
| --- | --- |
| FPS | 現在のフレームレート |
| Coordinates | プレイヤーの座標 |
| CPS | 左・右のクリック数を `8 \| 6 CPS` の形式で表示 |
| Armor Status | メインハンド、オフハンド、防具のアイコンと耐久値 |
| Ping | マルチプレイの通信遅延。シングルプレイでは値なし |
| TPS | サーバーから届く時刻更新をもとにした推定 TPS |
| Player Model | 視点の向きに合わせて少し回転するプレイヤーの 3D モデル |
| Item Total | メインハンドと同じ種類のアイテムのインベントリ内合計 |
| Compass | 視点に合わせてスクロールする方角と角度の目盛り |
| Image Overlay | ローカル画像やアニメーション GIF |

### Armor Status

従来型（隙間あり）、一体型（隙間なし）、バニラ型（ホットバーのテクスチャ）から選べます。横・縦並びに対応し、6枠を個別に切り替えられます。空枠の非表示、アイテムの個数、耐久バー、残量の数値・百分率も調整できます。低耐久時の枠の点滅、警告アイコン、音、アクションバー通知を設定できます。

バニラ型はホットバーやインベントリ・コンテナの左右に追従させるか、HUD Editor で自由に配置できます。バニラ型の大きさは Minecraft の GUI スケールに従います。

### Image Overlay

モジュール設定の **画像ファイル** から PNG、JPEG、GIF、BMP、WBMP、TIFF を選べます。GIF は繰り返し再生します。設定には選んだファイルのパスが保存されるので、画像を移動した場合はファイルを選び直してください。

## HUD Editor

設定画面の **HUD Editor** を選びます。直接開くキーは Minecraft のキー割り当てから設定できます。

| 操作 | 動作 |
| --- | --- |
| 左クリック / ドラッグ | パネルの選択 / 移動 |
| Ctrl＋右クリック | 選択に追加、または選択から除外 |
| 何もない場所からドラッグ | 範囲選択 |
| 四隅のハンドル / Ctrl＋ホイール | 選択中のパネルを拡縮 |
| 右クリック | 詳細設定、アンカー変更、自動配置への復帰など |
| 矢印キー / Shift＋矢印キー | 1 / 10 GUI px 移動 |
| Ctrl＋Tab / Ctrl＋Shift＋Tab | 次 / 前のモジュールを選択 |
| Ctrl＋Z / Ctrl＋Y | 元に戻す / やり直す（直近20操作） |
| H | 操作バーの表示・非表示 |
| Esc | 右クリックメニューを閉じる。メニューがなければ保存して Editor を閉じる |
| キャンセル | Editor での変更を破棄して閉じる |

操作バーでスナップ、グリッド、無効な HUD の点線プレビューを切り替えられます。点線のパネルは左クリックで有効にできます。

## Overlay

**その他 → Overlay** で Minecraft の演出や一人称表示を調整します。

| 項目 | 調整内容 |
| --- | --- |
| トーテム発動演出 | 大きさ（10〜200%）、高さ、速さ（25〜300%）。速さ100%は標準 |
| 燃えているときの炎 | 一人称の画面に重なる炎の高さ |
| ワールドの炎 | 火・ソウルファイアの大きさ（25〜200%）。画面を閉じるとチャンク描画に反映 |
| 手持ちアイテム | メインハンドとオフハンドそれぞれの大きさ・高さ |
| 盾 | 不透明度 |

## 設定ファイルと開発

設定はインスタンスの `config/etherhud.json` に保存されます。開発環境の既定パスは `run/config/etherhud.json` です。既存の設定で欠けている項目には既定値が入り、不正な JSON は `.bak` に退避します。

Windows は `./gradlew.bat build`、macOS / Linux は `./gradlew build` でビルドできます。ゲーム内で確認するときは `runClient` タスクを使います。

Minecraft 1.21.4 の角丸・円の描画には `ShaderManager#getProgramForLoading`、`DefaultVertexFormat.NEW_ENTITY`、共通の `RenderType` と `GuiGraphics` のバッファを使います。シェーダーは `assets/etherhud/shaders/core/` にあります。読み込みに失敗した場合や設定で無効にした場合は、矩形を組み合わせた描画に切り替わります。ワールドの火は Fabric Model Loading API の `modifyBlockModelAfterBake` で拡縮します。トーテムの再生速度は 1.21.4 の `GameRenderer` の演出時間と進捗計算に適用します。
